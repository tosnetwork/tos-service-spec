# Pre-Migration Deployment Evidence

These immutable records were produced before the public protocol and
repositories were renamed to TOS Service Protocol. They preserve their original
wire identifiers, schema names, hashes, addresses, and repository labels so the
audit trail remains truthful.

They are not evidence for `tos_service_v1`. Protocol-domain strings participate
in identifiers, signatures, manifest digests, Quote commitments, and execution
claims, so none of these records may be copied, relabeled, or cited as a current
Gate C–F acceptance result. Current evidence belongs in the parent
`deployments/` directory and must be generated from fresh current-domain
transactions.
